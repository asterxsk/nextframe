Concept from Discrete
Mathematics

Graph Theory

Degree, Connectivity, Path, Cycle, Eulerian and Hamiltonian Graphs,
Planar Graphs, and Graph Coloring.

Every idea used in this project comes directly from these seven topics. The
recommendation problem is treated as a question about a graph, and each
topic answers a different part of that question, from how popular a piece of
content is, to how a user's watch queue should be ordered, to how the
whole system is drawn and colored so it stays readable and varied.
  2 OVERVIEW

Project Overview

This project looks at how streaming platforms
decide what to show a user next, and treats that as
a graph problem.

T  he platform's users and content are represented as a graph, and
   each topic from the course is used to solve one specific part of the
   recommendation problem. Degree and connectivity are used to see

which content is actually popular and whether users naturally form groups

based on similar taste. They also help check whether the recommendation

system can reach every group of users, or whether some are left out.

Path length is used to measure how relevant a piece of content is to a user,
where a shorter path means a closer match. Cycles are used to spot a
common problem, where a user keeps getting shown the same narrow set of
content instead of anything new.

Eulerian and Hamiltonian graphs are used to build two different viewing
experiences. An Eulerian circuit is used to create a playlist that moves
smoothly between genres, and a Hamiltonian path is used to build a single,
ordered watch list for one user. Planar graphs and graph coloring handle
the final part of the project. A planar layout keeps the recommendation
graph easy to read without lines crossing over each other, and graph
coloring is used to make sure a user is not shown several very similar items
in a row.

A small sample dataset of users and content is used throughout the project,
so that each of these ideas can be shown working on the same example by
the end.
